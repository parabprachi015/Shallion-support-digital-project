# Data-Informed Website Development and Evaluation: Shallion Support

## 1. Project Background
Shallion Support is a community health support organisation providing practical, non-clinical support. During my professional placement, I worked on a digital information and website development project focused on improving how Shallion presents and communicates information through its online presence.

The project involved reviewing existing website content and information structure, considering how visitors access support and other information, using available Wix website analytics to understand visitor behaviour, and implementing practical improvements to website content, navigation and page structure.

## 2. Project Aim

The aim of this project was to review and improve Shallion Support's digital information and website presence by evaluating existing content, website structure and user pathways, analysing available website analytics, and implementing practical improvements to make information clearer and easier to access for visitors.
