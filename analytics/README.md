# Analytics

This folder contains the aggregate website analytics data, R analysis script, analysis findings and visualisations used for the project.

## Contents

- `analytics-summary.csv` – aggregate website analytics summary
- `page-visits.csv` – page-level visit data
- `page-performance.csv` – page performance data
- `search-performance.csv` – Google search-performance data
- `analytics-analysis.R` – reproducible R analysis script
- `analysis-findings.md` – written interpretation of findings
- `page-performance.png` – page performance visualisation
- `shallion_traffic_sources.png` – traffic-source visualisation
- `google-search-performance.png` – search-performance visualisation
- `search-performance-chart.md` – search-performance chart documentation
- `page-performance-chart.md` – page-performance chart documentation
- `top-search-queries-chart.md` – search-query chart documentation

## Reproducibility

The analysis script uses the CSV files in this folder and produces descriptive summaries and simple visualisations of the available aggregate analytics.

Only aggregate information is included in this portfolio.
