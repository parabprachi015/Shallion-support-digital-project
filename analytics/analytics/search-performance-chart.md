# Google Search Performance

The available Google search data showed strong performance for branded searches.

| Search query | Impressions | Clicks | CTR (%) | Average position |
|---|---:|---:|---:|---:|
| shallion support | 25 | 14 | 56.0 | 1.0 |
| shallion | 103 | 7 | 6.8 | 1.9 |

The results indicate strong visibility when users search specifically for Shallion. The difference in click-through rate between the two queries also highlights an opportunity to improve the presentation and visibility of the organisation for broader, non-branded searches.
