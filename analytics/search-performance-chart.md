# Google Search Performance Visualisation

The available search-performance data showed strong visibility for branded searches.

| Search query | Impressions | Clicks | CTR (%) | Average position |
|---|---:|---:|---:|---:|
| shallion support | 25 | 14 | 56.0 | 1.0 |
| shallion | 103 | 7 | 6.8 | 1.9 |

The results show particularly strong click-through for the "shallion support" query. The data also indicate that the website is performing strongly for searches containing the organisation's name.

The main opportunity identified is to increase visibility for relevant non-branded service-related searches.
