# Analytics Method

Website analytics were reviewed using the Wix Analytics dashboard during the placement.

The analysis considered:

- overall website sessions and unique visitors;
- traffic sources;
- page visits and page-level visibility;
- Google search impressions, clicks and average position;
- search queries;
- form submissions; and
- visitor behaviour where available.

The purpose of the analysis was to establish a baseline of website activity and identify areas where website structure, content, navigation and user pathways could be improved.

Only aggregate analytics were considered for the academic portfolio. No individual visitor information was used.
