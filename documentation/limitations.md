# Analytics Limitations

The website analysis was based on aggregate Wix Analytics and Google Search data available during the placement.

Several limitations should be considered when interpreting the findings.

## Aggregate data

The analysis uses aggregate website metrics rather than individual-level visitor data. Therefore, individual user journeys and characteristics cannot be examined.

## Observational analysis

The analytics describe patterns of website use but do not establish that a particular website change caused a change in visitor behaviour.

## Limited search-query coverage

The available Google search-query data were mainly based on branded searches such as "shallion" and "shallion support". This limits conclusions about visibility for non-branded service-related searches.

## Form activity

Volunteer-form activity provides evidence of views, starts and completed submissions, but it does not explain why visitors did or did not complete the form.

## Time period

The findings represent the analytics period available at the time of analysis. Website behaviour may vary over time because of changes in awareness, referrals, social activity, search visibility and website content.

## Future evaluation

A future review using the same measures would provide stronger evidence about whether website improvements are associated with changes in engagement, navigation and user actions.
