# Project Aim

The aim of this project was to review and improve Shallion Support's digital information and website presence.

The project focused on:

- reviewing existing website content and structure;
- considering how visitors can find information and access support;
- analysing available website analytics and search-performance data;
- identifying practical opportunities for improvement;
- implementing selected website content, navigation and usability improvements; and
- documenting the work to support future evaluation and development.
