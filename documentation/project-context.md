# Project Context

## Host Organisation

Shallion Support

## Placement Project

The placement focused on digital information, website content and systems development for Shallion Support and Shallion Dementia Support.

## Placement Context

The project was completed as part of the Professional Placement in Health Data Science. The work involved applying digital and analytical skills within a community health support organisation.

## Role

My role involved reviewing website content and digital information, analysing website structure and user pathways, using available website analytics, developing and updating website content, and documenting recommendations for improvement.

## Main Digital Environment

The main website development work was carried out using Wix. Other digital communication and information systems considered during the placement included email, WhatsApp, shared files and online meetings.

## Intended Contribution

The project aimed to support clearer presentation and organisation of information, improve the accessibility and usability of the website, and provide evidence that could inform future digital development.
