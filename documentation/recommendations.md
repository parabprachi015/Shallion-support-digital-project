# Recommendations

Based on the website review and available analytics, the following areas are recommended for continued development.

## 1. Strengthen Service Pathways

Make routes from the homepage to relevant support and information pages clear and easy to follow.

## 2. Improve Non-Branded Search Visibility

Develop relevant service-focused website content so that people searching for appropriate support, rather than only the Shallion name, have more opportunities to discover the organisation.

## 3. Improve Conversion Tracking

Review the visibility and design of contact and enquiry routes and consider how important user actions can be measured more consistently.

## 4. Continue Mobile Usability Checks

Because a substantial proportion of website activity occurs on mobile devices, responsive layouts, text readability, spacing and buttons should continue to be checked.

## 5. Monitor Website Performance

Repeat analytics reviews after major website changes to compare traffic, page engagement, search performance and recorded user actions over time.

## 6. Maintain Documentation

Keep clear records of website changes, decisions and future recommendations so that further development can build on the work completed during the placement.
