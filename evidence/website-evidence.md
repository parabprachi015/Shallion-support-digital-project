# Website Development Evidence

This section provides evidence of website development completed during the placement.

The evidence will demonstrate changes made to website structure, content, navigation, calls-to-action, service information and usability.

Selected before-and-after screenshots will be included where permission has been obtained from the host organisation.

## Main Evidence Areas

- Homepage improvements
- Shallion Support webpage
- Shallion Dementia Support webpage
- Support Us content
- FAQ and navigation improvements
- Calls-to-action and contact pathways
- Responsive desktop and mobile checks

Each selected example will be presented with context describing the issue or requirement, the change implemented and its intended purpose.
