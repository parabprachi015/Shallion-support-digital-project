# Project Summary

This placement project combined digital information review, website development and website analytics for Shallion Support.

## Project Focus

The work focused on reviewing the existing website and digital information environment, identifying opportunities to improve information structure and user pathways, analysing available Wix Analytics data, and implementing practical website improvements.

## Main Website Outputs

The main website development work included:

- Restructuring the Homepage to improve service visibility and information pathways.
- Developing a dedicated Shallion Support webpage from scratch.
- Developing a dedicated Dementia Support webpage from scratch.
- Redesigning the existing About Us webpage.
- Creating a dedicated Support Us webpage.
- Creating a dedicated Shop webpage from scratch.
- Reviewing FAQ content and improving navigation and calls-to-action.
- Checking updated pages across desktop and mobile views.

## Analytics Work

Available Wix Analytics and Google search-performance data were reviewed to establish a baseline for website activity.

The analysis considered website sessions, unique visitors, traffic sources, page visibility, search queries and volunteer-form activity.

The findings were used to support interpretation of website user pathways and identify areas for future development.

## Main Outcome

The project produced a more structured website, documented website development process and an analytics baseline for future evaluation.

The repository contains supporting data, visualisations, screenshots, analysis, recommendations and documentation so that the work can be reviewed and built upon in future.
